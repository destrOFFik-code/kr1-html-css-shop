# Практическая работа 7 Рефакторинг по БЭМ

Цель работы — привести классы учебного магазина и CSS к последовательной
БЭМ-структуре, сохранив оформление, навигацию и работу формы.
Расширение каталога, дополнительные страницы, FAQ и sticky-фильтр относятся
к самостоятельным доработкам КР №1 и не заменяют задачу рефакторинга.

## Блоки и элементы

| Компонент | Блок | Элементы |
| --- | --- | --- |
| Шапка | `site-header` | `site-header__inner`, `site-header__logo` |
| Меню | `site-nav` | `site-nav__list`, `site-nav__item`, `site-nav__link` |
| Карточка | `product-card` | `product-card__image`, `product-card__title`, `product-card__price`, `product-card__button` |
| Фильтры | `catalog-filters` | `catalog-filters__form`, `catalog-filters__group`, `catalog-filters__input` |
| Хлебные крошки | `breadcrumbs` | `breadcrumbs__link`, `breadcrumbs__current` |
| Форма | `order-form` | `order-form__field`, `order-form__label`, `order-form__input`, `order-form__actions` |
| Модальное окно | `order-dialog` | `order-dialog__title`, `order-dialog__product` |
| Отзыв | `review-card` | `review-card__title`, `review-card__quote`, `review-card__author` |
| FAQ | `faq` | `faq__item`, `faq__question`, `faq__answer` |

Карточки на главной и в каталоге используют один блок. Кнопка оформлена
самостоятельным блоком `button`; в карточке используется смесь классов
`button button--primary product-card__button`.

## Модификаторы

- `site-nav__link--active` — текущий пункт меню; сохраняется `aria-current`.
- `product-card--featured` — выделенная карточка лампы, пример модификатора блока.
- `button--primary`, `button--secondary` — варианты кнопок.
- `order-form--page` — размещение формы на отдельной странице.
- `order-form__input--checkbox` — вариант поля.
- `order-form__input--error` и аналогичные модификаторы — ошибки полей.

Модификаторы применяются вместе с базовыми классами. Идентификаторы нужны
для якорей, подписей полей, ARIA и JavaScript; оформление задаётся классами.

## Организация CSS и JavaScript

В начале CSS находятся общие переменные. Компоненты оформлены прямыми
классами без цепочек из вложенных тегов. Повторяющиеся правила `product-card`
и `order-form__actions` объединены. Сохранены Flexbox, Grid, медиазапросы,
видимый фокус и настройки уменьшения движения.

JavaScript использует актуальный класс `product-card__button` и атрибуты
`data-product` для открытия окна. Модификаторы ошибок синхронизированы
с `aria-invalid`. На странице заявки допускаются только позиции,
уже перечисленные в HTML-списке.

## Самопроверка

1. Блок — самостоятельный компонент, элемент — его часть, модификатор — вариант
   или состояние. Пример: `product-card`, `product-card__price`, `product-card--featured`.
2. Элемент записывается через `__`, модификатор — через `--`.
3. Имена по назначению остаются понятными при изменении оформления.
4. Прямые классы уменьшают зависимость CSS от вложенности HTML.
5. После переименования нужно проверить JS-селекторы, окно, форму и ошибки.
6. Успешный рефакторинг сохраняет поведение страниц и упрощает поддержку стилей.
